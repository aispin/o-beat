# ABC 谱引擎

> 一句话：**谱写音符，风格写音色。** 一份谱换一行 `%%OB style ...` 就是另一种风格；
> 加一首曲子 = 放一个 `.abc` 进 `apps/pwa/src/songs/` 并在 `abc/songs.ts` 登记一行。

## 0. 一页速查

| 我想…… | 改哪里 |
|---|---|
| 改某个音的**音高** | `src/songs/<id>.abc`，把那个音名换掉（`g` → `a`） |
| 改某个音的**长短** | 音名后面的数字：`4` = 四分音符，`8` = 半音符，`2` = 八分 |
| 改**和弦** | 小节开头的 `"F"` → `"Dm"` |
| 改**鼓** | `%%OB drums kick=... snare=... hat=off` |
| 改**混音**（闷 / 亮、谁大声） | `%%OB mix cut=... lead=... comp=... bass=... vol=...` |
| 换**整套乐器** | `%%OB style lofi` → `rock` / `classic` / `cyber` / `pixel` |
| 加**一首新曲** | 抄一份 `.abc`，改 `X:` `T:` `Q:` `K:` 与音符，登记到 `abc/songs.ts` |
| 看**有没有写错** | `pnpm --filter @o-beat/pwa abc:check` |

## 1. 为什么是 ABC

手写字符串（`'76 . . . 79 . . .'`）能写动机，但加曲要改 TS、"一小节 16 个字符"读起来像方阵，
而且谱和风格粘在同一个对象里 —— 想听摇滚版就得复制一份再改七个字段。

ABC 的好处是**谱是谱，风格是风格**：

```
"Am" c4 z2 e2 g8 |      ← 谱：谁在什么时候响
%%OB style lofi        ← 风格：用什么响、多大声、什么空间
```

同一条旋律换 `%%OB style rock`，音色、鼓、混音、底噪整套换掉，音符一个不动。
这也是 [`tech-lofi.md`](tech-lofi.md) §9「四件套」的前置：四件套描述的是**风格**，
现在它和**谱**分开放了。

为什么不用 abcjs：它是 512 KB，而且 `parseOnly` 给的是排版 AST（`d` 的 `pitch` 是 8，
音级不是 MIDI），调号、格号、和弦对位仍要自己算。完整比较见
[ADR 0003](adr/0003-abc-score-engine.md)。

## 2. 一个文件长什么样

`apps/pwa/src/songs/breath.abc`（完整文件，注释是原文）：

```
X:1
T:长呼吸
C:o-beat
M:4/4
L:1/16
Q:1/4=64
K:Am
%%OB style lofi

V:1 name="lead"
"Am" c4 z2 e2 g8 | z4 c4 z8 |
"F"  f4 z2 a2 g8 | z4 g4 z8 |
"C"  e4 z2 g2 e4 d4 | z4 c4 z8 |
"G"  d4 z2 B2 d4 z4 | z4 g4 z8 |

V:2 name="bass" clef=bass
A,,8 z8 | z8 G,,8 |
F,,8 z8 | z8 A,,8 |
C,,6 G,,10 | z12 D,,4 |
G,,8 z8 | z8 E,,8 |
```

逐行：

| 行 | 意思 |
|---|---|
| `M:4/4` | 每小节 4 拍。只支持 3/4 与 4/4 —— 引擎的格子是 12 或 16 |
| `L:1/16` | 不写数字时，一个音 = 一个十六分音符。**建议永远写 1/16**，这样一个数字就是引擎的一格 |
| `Q:1/4=64` | 每分钟 64 个四分音符。**以谱面为准**，`game.ts` 里的 bpm 只做交叉检查 |
| `K:Am` | 调号。`K:D` 会让 `f` 自动是 F#，谱上不用写 `^f` |
| `V:1 name="lead"` | 声部名决定它进哪一层。`lead` = 旋律，`bass` = 低音 |
| `"Am"` | 和弦记号，落在这小节**第 0 格**。引擎只支持"整小节一个和弦" |
| `c4 z2 e2 g8` | 第 0 格 c 响 4 格，第 4 格空 2 格，第 6 格 e 响 2 格，第 8 格 g 响 8 格 |
| `A,,8` | 大写 = 中央 C 那个八度，每个 `,` 低一个八度。`A,,` = A2 = MIDI 45 |

## 3. 支持的写法

### 3.1 音高

| 写法 | 音高 | MIDI |
|---|---|---|
| `C` | C4 | 60 |
| `c` | C5 | 72 |
| `c'` | C6 | 84 |
| `C,` | C3 | 48 |
| `C,,` | C2 | 36 |
| `^F` / `^^F` | 升 / 重升 | +1 / +2 |
| `_B` / `__B` | 降 / 重降 | −1 / −2 |
| `=F` | 还原 | 0 |

临时记号**只管本小节**，过了小节线回到调号。`^F` 之后再写 `F`，同一小节里仍是 F#。

### 3.2 时值

`L:1/16` 时：

| 写法 | 几格 | 相当于 |
|---|---|---|
| `c` | 1 | 十六分 |
| `c2` | 2 | 八分 |
| `c4` | 4 | 四分 |
| `c8` | 8 | 半音符 |
| `c16` / `c` + `|` | 16 | 全音符 / 整小节 |
| `c3` | 3 | 附点八分（`3` 就是格数，不必写成附点） |
| `c2/3` | 1（取整） | 三连音 —— **不在十六分格上，会警告并取整** |
| `c-` | — | 连音线：和下一个同音合并成一个长音 |
| `z` / `z4` | 1 / 4 | 休止 |
| `x` | 1 | 不发音的休止（占位用） |
| `Z` | 整小节 | 全小节休止 |

### 3.3 小节线与反复

| 写法 | 意思 |
|---|---|
| `|` `||` `|]` `[|` | 小节线，都只是"换小节" |
| `|:` … `:|` | 反复一次（整小节，不支持半小节反复） |
| `::` / `:|:` | 结束上一段并开始下一段 |

### 3.4 和弦与声部

| 写法 | 意思 |
|---|---|
| `"Am"` `"F"` `"C/G"` `"F#m7"` | 和弦记号，落在下一个事件上 |
| `[CEG]4` | 同时响三个音（和弦）。旋律层只取最高音 |
| `V:1 name="lead"` | 声明 / 切换到某声部 |
| `%%comment` 与 `%` 行 | 注释，不参与解析 |

**和弦名的能力边界**：大三、小三、`dim`、`aug`、`sus2`、`sus4`、`5` 是完整支持的；
`maj7` / `m7` / `9` / `add9` 这类延伸音**按三和弦播放**并在 DEV 控制台警告，
因为引擎的和声层只有三个音（`comp` 的每种型最多用三个，`pad` 是三个 + 高八度根音）。

## 4. `%%OB` 指令

`%%OB` 是本项目自己的扩展（`OB` = O My Beat）。除了 `style`，都是"逐字段覆盖"：

| 指令 | 参数 | 说明 |
|---|---|---|
| `style` | `lofi` / `rock` / `classic` / `cyber` / `pixel` | 取整套预设，必须写在其它 `%%OB` 之前 |
| `inst` | 音色名 | 主奏音色：`softPiano` `epiano` `piano` `violin` `egt` `pluck` `bell` `chipLead` … |
| `comp` | 型 + 音色 + `oct=` `gain=` `pat=` | 例如 `comp pick nylon oct=12 gain=0.30` |
| `pad` | `gain=` `rev=` `voices=` `oct=` | 铺底垫。`gain=0` 等于关掉这一层 |
| `bass` | 音色 + `gain=` `oct=` | 没有 `V:bass` 声部时才用它的节奏型 |
| `drums` | `kit=` `kick=` `snare=` `hat=` `open=` | `kick=0,10` 是十六分位；`hat` 只能是 `eighth` / `16` / `off` / `none` |
| `mix` | `cut=` `lead=` `comp=` `bass=` `vol=` | `cut` 是主链低通（lofi 3200 → 闷） |
| `tape` | 0–1 | 磁带底噪（嘶声 + 噼啪） |
| `swing` | 秒 | 奇数十六分位推后多少秒。0.012 ≈ 8.5% |
| `echo` | 0–1 | ping-pong 回声，电子用 |

五个预设的差别（`abc/style.ts`）：

| style | 主奏 | 和声 | 低音 | 鼓 | cut | 其它 |
|---|---|---|---|---|---|---|
| `lofi` | softPiano | nylon arp8 | bassLofi line | lofi 合成 | 3200 | tape 0.13、swing 0.012、pad |
| `rock` | egt 失真 | egt riff | ebass eighth | acoustic | 6400 | vol 0.55（给失真留余量） |
| `classic` | violin | piano waltz | cello waltz | 无 | 11000 | vol 1.5 |
| `cyber` | pluck | epiano stab | sub half | kpr77 | 9000 | echo 0.22 |
| `pixel` | chipLead | chipLead arp8 | chipBass | chip | 8200 | 全合成 |

> 只有 `lofi` 的数值是"照着现有两首调出来的"；其余四个是**起点**，不是复刻
> `neon` / `city` / `waltz` / `live` / `arcade`。

## 5. 从谱到声音

`abc/toScore.ts` 把谱 + 风格合成引擎要的 `Score`，映射关系只有五条：

| 谱 | Score 字段 | 备注 |
|---|---|---|
| `V: name="lead"` | `lead` + `leadDur` | 每个音的时值单独记，不再统一 3.2 格 |
| `V: name="bass"` | `bass.line` | 时值仍按"到下一个音的距离 × 0.97"算 —— 连奏是低音的听感来源 |
| `"Am"` 记号 | `prog` + `chords` | 按小节对齐；没写记号就退回曲目定义的四和弦循环 |
| `M:` / `Q:` | `steps` / `bpm` / `step` | 以谱面为准 |
| （其余） | `inst` / `comp` / `pad` / `drums` / `mix` / `tape` / `swing` / `echo` | 全部来自 `%%OB` 与风格预设 |

优先级：`song.abc`（自带谱）> 谱库 `ABC_SONGS[id]` > `compose.ts` 手写 > 参数生成。
缓存键包含谱面原文，所以同一首曲子反复进出首页听到的一定是同一段。

### 5.1 换引擎后的实测

把两首谱搬到 ABC 之后，用同一套录音链路（11 秒、`MediaRecorder` 抓总线）与 v1.6 对比：

| 曲目 | 版本 | RMS | <120 | 120–400 | 400–2k | 2–6k | >6k |
|---|---|---|---|---|---|---|---|
| 长呼吸 | v1.6 | −19.9 | −22.2 | −25.4 | −28.8 | −43.5 | −56.4 |
| 长呼吸 | ABC | −20.3 | −22.7 | −25.7 | −29.0 | −43.2 | −55.5 |
| 雨窗午后 | v1.6 | −20.1 | −22.4 | −25.7 | −28.6 | −43.4 | −57.9 |
| 雨窗午后 | ABC | −20.5 | −23.0 | −26.1 | −28.6 | −43.1 | −56.7 |

四个音乐频段最大差 **0.6 dB**，RMS 差 **0.4 dB**：听感上就是同一段音乐。
`>6k` 那档差 0.9–1.2 dB，是因为磁带噼啪每次进循环的位置是随机的，这一档本来就只有 −57 dB，
不代表音色变了。

## 6. 加一首新曲

1. **抄一份谱。** `cp apps/pwa/src/songs/breath.abc apps/pwa/src/songs/<id>.abc`。
2. **改头。** `X:` 换个号、`T:` 写名字、`Q:` 写速度、`K:` 写调。
3. **写旋律。** 一小节一行，用 `M:` 与 `L:` 对上格子；`"和弦"` 放在换和弦的那一格。
4. **写低音**（可选）。没有 `V:bass` 就用风格预设的低音型。
5. **登记。** `abc/songs.ts` 加一行 `import` 与一个键；`game.ts` 的 `SONGS` 加一条
   （id 必须一致，bpm / meter 与谱面一致，`chords` 留给对局衬底用）。
6. **验。** `pnpm --filter @o-beat/pwa abc:check`，然后进首页听一遍。

## 7. 调优示范

以下四条都是真实改过的（`~/Desktop/o-beat-abc谱引擎/` 里有对应的 mp3）。

### 7.1 改一个音：第 5 小节抬高一步

```
- "C"  e4 z2 g2 e4 d4 | z4 c4 z8 |
+ "C"  e4 z2 a2 e4 d4 | z4 c4 z8 |
```

第 4 小节落在 G 上，原本第 5 小节回到 G（同音），改成 A 之后旋律**继续往上走**，
到第 7 小节的 D 才落。自检会立刻看到 `0:76 6:79 8:76 12:74` → `0:76 6:81 8:76 12:74`。

### 7.2 加一个经过音：贝斯从 G 走到 D

```
- C,,6 G,,10 | z12 D,,4 |
+ C,,6 G,,10 | z8 G,,4 D,,4 |
```

第 6 小节和弦是 C，第 8 格补一个 G（五音）再落到 D，两拍之内走完一个五度。
因为低音的时值按"到下一个音的距离"算，这一改**自动变成连奏**，不需要改别的地方。

### 7.3 换和弦：F → Dm

```
- "F"  f4 z2 a2 g8 | z4 g4 z8 |
+ "Dm" f4 z2 a2 g8 | z4 g4 z8 |
```

`Dm` = D F A，旋律的 f 与 a 都还在和弦里，但**根音从 41 变成 38**，
琶音与铺底跟着走，色彩立刻从大调变暗。改和弦只影响和声层，旋律一个音都不用动。

### 7.4 换风格：同一份谱换摇滚

```
- %%OB style lofi
+ %%OB style rock
```

音符、和弦、速度全不变，换来的是：`egt` 失真主奏、八分 power chord、acoustic 鼓组、
cut 6400、没有铺底、没有底噪、不摇摆。试听第 3 首就是这一版 ——
同一段旋律在摇滚编制下"句子还是那个句子，衣服全换了"。

### 7.5 改鼓与混音

```
%%OB drums kick=0,10 snare=4,12 hat=off     →  hat=16（十六分闭镲，立刻变紧）
%%OB mix cut=3200                           →  cut=5000（亮一档，人声感更强）
%%OB tape 0.13                              →  tape=0（去掉噼啪，变干净）
%%OB swing 0.012                            →  swing=0（正拍，变"直"）
```

改完先跑自检（确认没有写错），再听 11 秒录音对比五段能量 —— 方法见
[`tech-lofi.md`](tech-lofi.md) §6。

## 8. 已知不支持

| 写法 | 现在会怎样 |
|---|---|
| 跳房子 `[1` / `[2` | 警告，按顺奏展开（不重复） |
| 不等分音符 `>` `<` | 警告，按正常时值（三连音会被压平） |
| 半小节反复 / 反复嵌套 | 不支持，只做整小节一次反复 |
| 装饰音 `{g}` | 忽略（不占时值） |
| 歌词 `w:` / 排版指令 `%%score` | 忽略 |
| 七音 / 九音 / 斜杠低音 | 按三和弦播放，DEV 控制台警告 |
| 一小节内换和弦 | 按整小节算，警告 |

## 9. 文件与命令

```
apps/pwa/src/engine/abc/
├─ parse.ts     ABC → AbcTune（音高/时值/小节/和弦/声部），560 行（含注释）
├─ style.ts     五个风格预设 + %%OB 指令解释
├─ toScore.ts   谱 + 风格 → Score（五层映射）
├─ songs.ts     曲目 id → 谱面原文
└─ index.ts     对外只露 parseAbc / scoreFromAbc / STYLES / ABC_SONGS

apps/pwa/src/engine/chords.ts   和弦名 → 三个音（手写编曲与 ABC 共用）
apps/pwa/src/songs/*.abc        谱：一首一个文件
apps/pwa/scripts/abc-check.mjs  25 项自检
```

```bash
pnpm --filter @o-beat/pwa abc:check    # 解析器 + 两首谱逐格 + 换风格
pnpm --filter @o-beat/pwa typecheck
pnpm --filter @o-beat/pwa build
```

## 10. 反例

| 做法 | 结果 | 教训 |
|---|---|---|
| 用 `L:1/8` 写谱 | 一个数字是两格，读谱时每格都要心算 | 固定 `L:1/16`，数字即格数 |
| 把 `|:` 当普通小节线处理 | 谱首的 `|:` 多吃一小节，整首错位 | `|:` 是标记不是线；它前面已经有小节线时不再换行 |
| 用大写 `b` 写 B4 | 写成 `b` = B5，高了一个八度 | 大小写是八度，不是音名 |
| `"Am7"` 期待七音 | 只有三个音，七音消失 | 引擎只支持三和弦；要七音得改和声层 |
| 在 `V:bass` 里写 `z` 填满整小节 | 低音时值按"到下一个音"算，休止不影响 | 休止只影响位置，不影响上一个音的长度 |
| 以为改 `game.ts` 的 bpm 会改速度 | 谱面 `Q:` 优先，改 `game.ts` 只在 DEV 警告 | 速度属于谱 |
