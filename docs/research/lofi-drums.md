# Lofi 鼓组：不用采样，能捏出来吗

> 调研时间：2026-10-24 · 状态：**结论已跑通，未改动产品代码**
> 试听素材：`~/Desktop/o-beat-lofi鼓组试听/`（7 个 mp3）

---

## 1. 问题

> 「当前鼓的采样比较硬，特别是军鼓，适合摇滚风格，但与 lofi 风格格格不入。」

先确认这不是错觉，也不是"换个采样"能解决的：

| 事实 | 数值 |
|---|---|
| lofi 场景当前用 `kpr77` 鼓组（Korg KPR-77，1983 年机器） | 4 个文件，16.5 KB |
| 军鼓采样时长 | 125 ms（**比它的尾巴还短**，一响就没了） |
| 军鼓瞬态（10%→90% 包络） | 2 ms，几乎垂直 |
| 军鼓 2–6 kHz 能量占比 | −11.0 dB（相对总能量） |
| 军鼓频谱质心 | 4610 Hz |

问题不在"机器鼓不够低保真"——KPR-77 本身很脏。问题是**它是机器军鼓**：短、硬、噪声明亮。
而 lofi hiphop 里的军鼓，来源基本是**真实套鼓的采样再降调**：瞬态被拉钝、频谱整体下移、尾巴变长。
两者不是同一个乐器，调 EQ 也换不过来。

**所以问题可以拆成一句可验证的话**：不用采样，能否用 WebAudio 合成出一个瞬态钝、2–6 kHz 收敛、带鼓皮音高的军鼓？

---

## 2. 结论

**能。** 三个技术支点，缺一不可：

1. **分层噪声**，不是一层。响弦（snare wires）在 800 / 2400 / 7000 Hz 三个区间各有不同衰减，一层带通永远像"白噪刷一下"。
2. **双模态鼓皮**。军鼓两个圆膜模态频率比约 1 : 1.58，两个正弦 + 轻微下滑音高，才有"鼓"的体积感；只给噪声就是 808 军鼓。
3. **起音 4–8 ms + 低通 5–6 kHz**。这两条是"硬度"的开关。采样军鼓的 2 ms 垂直起音 + 6 kHz 以上完整保留，就是它听起来像摇滚的原因。

实测结果（同样 4 小节、同样摇摆与力度、电平对齐 ±0.5 dB）：

| 频段 | 现有采样 | 合成 lofi | 差 |
|---|---|---|---|
| < 120 Hz | −20.0 dB | −20.2 dB | −0.2 |
| 120–400 Hz | −23.4 dB | −22.9 dB | +0.5 |
| 400–2 kHz | −29.0 dB | −29.2 dB | −0.2 |
| **2–6 kHz** | **−37.4 dB** | **−40.9 dB** | **−3.5** |
| > 6 kHz | −42.4 dB | −42.8 dB | −0.4 |

低频和中频几乎一模一样，**只在"硬"所在的 2–6 kHz 少了 3.5 dB**。这就是想要的差异，而且不是靠整体调暗换来的。

**代价说清楚**：约 120 行合成代码（一次性），加每首曲子可能要按需调 2–3 个参数。**体积上毫无收益**——kpr77 只有 16.5 KB，合成不会更小。价值全在"可调"和"每次击打不完全一样"。

---

## 3. 为什么现有军鼓硬：拆成三层看

真实军鼓 = 鼓皮（低频、有音高）+ 响弦（中高频噪声）+ 房间（尾巴）。三者时间常数不同。

| 层 | 现有采样 | lofi 应有的样子 |
|---|---|---|
| 鼓皮 | 被噪声盖住，听不出音高 | 165–190 Hz 可辨，衰减 190–240 ms |
| 响弦 | 全带宽，2–6 kHz 是主体 | 三层带通，2–6 kHz 降 3 dB，尾巴 200–300 ms |
| 瞬态 | 2 ms 垂直 | 4–8 ms 斜上去（"钝"） |
| 房间 | 靠总线混响，干声比例高 | 短房间 0.55 s，干湿比更靠湿 |

## 4. 调研方案

### 4.1 方法

不用另外写一套 DSP 模拟——直接在 **OfflineAudioContext** 里跑，和线上引擎是同一套 WebAudio API、同一批节点。
这样"实验里成立"就等于"实现后成立"，不存在移植损耗。

流程：Chrome headless → 载入实验页 → `startRendering()` → 16 bit WAV → ffmpeg 转 192 kbps mp3。

### 4.2 对照组设计

单一变量：**只换鼓源**。编曲、摇摆、人性化、和声、主链（饱和 / 低通 / 压缩 / 房间）全部相同。

| 组 | 内容 |
|---|---|
| A | 现有 `kpr77` 采样（基线） |
| B | 采样降调 0.78 + 低通 4.8 kHz（**最便宜的替代方案**） |
| C | 合成：单层噪声（最简） |
| D | 合成：三层噪声 + 双模态鼓皮（推荐） |
| E | D + 12 bit 量化 + 更强饱和（更脏） |
| F | D + 鼓皮降到 165 Hz、起音 8 ms、尾巴拉长（更糯） |

### 4.3 指标与判据

客观四项，用来证明"确实变软了"而不是"变小了"：

| 指标 | 算法 | 判据 |
|---|---|---|
| 峰值 / RMS | 逐采样 | A 与 D 相差 ≤ 1 dB（否则是在比响度） |
| 瞬态时间 | 包络 10%→90% | D ≥ 4 ms，A ≤ 2 ms |
| −20 dB 衰减时间 | 包络 | D ≥ 70 ms |
| 2–6 kHz 能量占比 | FFT 分频段 | D 比 A 低 3–4 dB |

主观三项，只能靠耳朵：**软硬**（有没有"啪"的脆感）、**体积**（像不像一个鼓）、**在歌里**（跟电钢和贝斯抢不抢）。

### 4.4 公平性控制

- 同一段 4 小节 68 BPM，kick `[0, 1.75, 2.5]`、snare `[1, 3]`、八分踩镲、swing 0.07、人性化 ±6 ms；
- 采样踩镲按线上引擎的 0.09 s 淡出处理，避免"实验里采样尾巴更长"的假差异；
- 三段成品 RMS 控制在 −18.0 / −18.0 / −18.4 dB。

## 5. 测量结果

### 5.1 军鼓 6 方案

| # | 方案 | 峰值 | 瞬态 | −20 dB 衰减 | 质心 | 2–6 kHz | 听感关键词 |
|---|---|---|---|---|---|---|---|
| 1 | A 现有采样 | −4.1 | 2 ms | 73 ms | 4609 | −11.1 | 硬、脆、像军鼓但不是 lofi |
| 2 | B 采样降调 | −3.8 | 4 ms | 97 ms | 4203 | −13.1 | 立刻对味，但"糊"、缺鼓皮 |
| 3 | C 单层噪声 | −5.9 | 2 ms | 75 ms | 4527 | **−2.6** | 最差：比采样还刺，像白噪 |
| 4 | **D 三层 + 鼓皮** | **−3.9** | **4 ms** | **57 ms** | **4247** | **−13.5** | 软、有体积、尾巴偏短 |
| 5 | E D + 12 bit | −4.0 | 4 ms | 67 ms | 4338 | −13.1 | 更脏更旧，颗粒感重 |
| 6 | F D + 更糯 | −4.2 | 4 ms | 73 ms | 4492 | −12.7 | 最"贴"lofi，鼓皮低、尾巴长 |

关键发现：

- **C 组证明了"一层噪声不行"**：2–6 kHz 反而比采样高 8.5 dB，因为它没有鼓皮、没有分层衰减，只剩噪声的宽带能量。这是最容易踩的坑。
- B 组（采样降调）性价比极高：只改 `playbackRate` 和一级低通，5 行代码，听感立刻从摇滚变 lofi。代价是**每首歌的军鼓都是同一个音色**，且降调会让镲片一起变闷（这条在整段 A/B 里能听出来）。
- D 的 −20 dB 衰减只有 57 ms，比采样短。所以给出了 F。

### 5.2 底鼓

| 方案 | 峰值 | RMS | 衰减 | 低音质心 | 听感 |
|---|---|---|---|---|---|
| 采样 | −3.9 | −19.0 | 103 ms | — | 点击感强，尾巴干净 |
| 采样降调 | −2.8 | −17.5 | 125 ms | — | 更肥，但糊 |
| **合成** | **−5.1** | **−19.4** | **95 ms** | 3601 | 圆、无「哒」、和贝斯不打架 |
| 合成更紧 | −5.4 | −19.9 | 71 ms | 3600 | 更干，适合密集编排 |

底鼓的合成难度最低——正弦扫频 108→45 Hz，加 12 ms 的低通噪声当"槌头"，就够用。真正的差别在**槌头**：采样的槌头是 3 kHz 的"哒"，那是摇滚的语法；lofi 要削到 1.5 kHz 以下，变成"噗"。

### 5.3 踩镲

| 方案 | 峰值 | RMS | −20 dB 衰减 | 质心 | 听感 |
|---|---|---|---|---|---|
| 采样 | −7.7 | −29.5 | 179 ms | 6910 | 有尾巴，像 break |
| 合成两层 | −7.6 | −34.6 | 41 ms | 7172 | 点更清楚，尾巴偏短 |
| 合成加金属 | −6.0 | −32.4 | 99 ms | 7730 | 有镲片泛音，略 808 |
| 合成更短 | −6.1 | −38.6 | 25 ms | 7336 | 最"点"，适合快编 |

踩镲是最不需要纠结的一件：两层噪声（62 ms 的"嗒" + 260 ms 低电平余响）已经能骗过耳朵。**唯一要注意的是电平**——合成踩镲的 RMS 比采样低 5 dB，只对峰值会让它在混音里"消失"，必须按 RMS 校。

## 6. 推荐配方（可直接抄）

以下是跑通的那一组。参数名与实验页一致，落地时直接搬。

### 军鼓（D 组）

```ts
body: 186, bodyAmt: 0.40, modes: [[1, 1], [1.58, 0.45]], toneDecay: 0.19,
layers: [
  { bp: 900,  q: 1.00, amt: 0.16, decay: 0.25, hp: 320  },  // 响弦的"肉"
  { bp: 2600, q: 0.70, amt: 0.20, decay: 0.23, hp: 900  },  // 主体，别给多
  { bp: 7200, q: 0.60, amt: 0.055, decay: 0.07, hp: 4200 }, // 一点空气，别再多
],
attack: 0.004, lp: 6000, hp: 95, drive: 1.7, pink: true
```

| 参数 | 作用 | 调大 / 调小的听感 |
|---|---|---|
| `body` | 鼓皮基频 | ↑ 更"紧"更小军鼓；↓ 更"糯"更胖 |
| `bodyAmt` | 鼓皮比例 | ↑ 更像鼓、更像真鼓；↓ 更像 808 |
| `attack` | 起音时间 | ↑ 更钝（lofi 主开关，4–8 ms） |
| `lp` | 总低通 | 5000 更闷，6500 开始出现"脆" |
| `drive` | 饱和 | ↑ 更脏、更旧；> 2.5 开始糊 |
| 层 2 的 `amt` | 2–6 kHz 的主控 | ↑ 立刻变硬（这里是最敏感的一个数） |

### 底鼓

```ts
f0: 108, f1: 45, sweep: 0.09, decay: 0.38, attack: 0.004,
click: 0.09, clickLp: 1500, drive: 1.5, lp: 5000
```

### 踩镲

```ts
layers: [
  { bp: 7800, q: 0.7, amt: 0.90, decay: 0.062 },
  { bp: 6200, q: 0.9, amt: 0.40, decay: 0.26  },
],
hp: 4800, lp: 11500
```

### 主链（这一段决定了"磁带味"）

```ts
highpass 35 Hz → tanh 饱和 1.2–1.5 → lowpass 7200（更暗用 5200）
→ compressor(threshold −20, ratio 2.6, attack 8 ms, release 180 ms)
→ 短房间 0.55 s，湿度 0.16
```

## 7. 与采样比，值不值

| 维度 | 采样（现状） | 合成（推荐） |
|---|---|---|
| 真实感 | 真鼓录音，天然可信 | 得靠参数调，A/B 能听出是"合成"的 |
| 单次差异 | 每次同一段波形 | 每击噪声随机、音高微漂，天然不重复 |
| 可调性 | 只有音量和 playbackRate | 音高、衰减、鼓皮比例、脏度都能按曲子调 |
| 体积 | 16.5 KB | 0 |
| CPU | 一次解码，播放几乎零成本 | 每击 ~10 个短命节点（与现有 chip 鼓同量级） |
| 移植小程序 | 需要 mp3 解码 | 纯 WebAudio 1.0 节点，更好移 |
| 风险 | 无 | 参数调错会变成"塑料鼓"，需要耳朵验收 |

**一句话**：采样胜在省事，合成胜在可控。我们不是第一次做这件事——`chip` 鼓组已经是合成的（像素心跳用的就是它），这条路在工程上早已验证。

## 8. 如果决定做，落地路径

不改现有三套鼓组，**新增第 4 套** `lofi`：

1. `sfx.ts`：`KIT` 表加 `lofi`；`drum()` 里 `kit === 'lofi'` 走合成分支（结构照抄 `chipDrum()`，参数换成上面那张表）。
2. `sfx.ts`：加一个 `synthKit` 参数对象；顺手把 `pinkNoise` 缓存成 buffer（现在噪声 buffer 是白噪，粉噪要新生成一次）。
3. `backing.ts`：`GROOVE.lofi.kit` 由 `kpr77` 改成 `lofi`。
4. 重新校准 `BUS_DEF` 里 kick/snare/hat 的增益（合成件 RMS 与采样不同，不校会整体变响或变轻）。

估计一个批次能完成，然后按现有流程做 RMS / 分频段 / 削波三项验收。

## 9. 需要你裁决的三点

1. **02 还是 03**：`02 合成 · Lofi 鼓组`（明亮一点，军鼓 2–6 kHz −13.5）还是 `03 更暗更糯`（整体低通 5.2 kHz，> 6 kHz 再低 3.5 dB）。后者更像磁带，前者更清楚。
2. **军鼓选 4 还是 6**：4 更"干净利落"，6 更"糯"（鼓皮 165 Hz、尾巴长 30%）。
3. **要不要留采样兜底**：合成调不好时可以一键切回 `kpr77`；也可以直接把 lofi 场景的采样删掉，彻底不回头。
