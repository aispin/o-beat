# O My Beat · PRD v1

> 产品目标：**可玩性高、能解压、能练「节奏感」与「音感」** 的竖屏小程序音乐游戏。
> 本文是设计与数值的唯一依据；`prototype/` 是交互与视觉的唯一依据。

版本：v1.0 · 2026-10-23

---

## 1. 产品定义

**跟着音乐敲准点、按对音，音乐永远好听。你只是加入它，而不是毁掉它。**

三个价值支柱：

| 支柱 | 玩家感知 | 机制承载 |
|---|---|---|
| 节奏感 | "我踩点越来越稳了" | 固定毫秒判定 + 偏差 σ（稳定度） |
| 音感 | "我听得出下一个音在哪" | 旋律家 5 列五声音高 + 辅助渐隐 |
| 解压 | "不用赢，也不会输" | 无失败、backing 不断、正向反馈 |

## 2. 目标用户与场景

| 场景 | 时长 | 需求 | 设计响应 |
|---|---|---|---|
| 睡前放松 | 3–5 分钟 | 不想动脑、不想挫败 | 55 秒一局、无失败、BPM 65–75 |
| 通勤碎片 | 1–2 分钟 | 随时开始随时停 | 秒开局、暂停无损、退出保留成绩 |
| 认真练习 | 10 分钟+ | 想看到进步 | 三维结算 + 偏差诊断 + 稳定度趋势 |

非目标：竞技、排行榜、社交、养成。v1 不做。

---

## 3. 核心循环

```
选模式 → 选曲 → 调难度 → [4 拍倒数] → 演奏 16 小节 → 三维结算 → 再来 / 返回
```

单局 16 小节，四段结构，55 秒左右。

## 4. 舞台与布局

### 4.1 屏幕分区

```
0%    ┌───────────────┐
      │  HUD 分数 / 连击 │
8%    ├───────────────┤
      │               │
      │    坠落区      │  ← 音符自 -60px 处生成，向下坠落
      │               │
78%   ├───────────────┤  ← 判定线（全宽，随拍脉动）
      │    击打区      │  ← 拇指自然落点
100%  └───────────────┘
```

| 常量 | 值 | 说明 |
|---|---|---|
| 判定线 | `0.78 × 屏高` | 给拇指留 22% 空间 |
| 生成线 | `-60px` | 屏幕外 |
| 预读时间 | 1.8s（可调 1.2–2.5s） | 定义"速度"，不直接用 px/s |
| 下落速度 | `(0.78H + 60) / 预读` | 812 屏约 385 px/s |
| 音符尺寸 | 36 × 18 px 胶囊 | 圆角 9 |

**纵向相对横向的红利**（竖屏 375×812）：

| | 横向（demo） | 纵向（v1） |
|---|---|---|
| 预读长度 | 292 px | 693 px |
| 8 分 @70BPM 间距 | 31 px | 155 px |
| 音符占位 | 28 px | 18 px |
| 结果 | 必然重叠 | 留白 8 倍 |

### 4.2 关于「音高轴」的修正（重要）

v0 草案写"旋律轨内高度 = 音高"。**在纵向下落中这是不可实现的**：y 轴已经被时间占用，音符的高度就是它到判定线的距离，无法同时表达音高。

因此音高必须走 **x 轴**：

> **MELODY 轨内部再分 5 列，横向位置 = 五声音阶的 5 个音高。**

这与钢琴类手游（Piano Tiles）的成熟解法一致，也是唯一能在纵向滚动里做空间化音高判定的方式。

## 5. 模式 A：鼓手（练节奏感）

4 轨纵向，单手双拇指即可上手。

| 轨 | 音色 | 谱面角色 | 颜色 |
|---|---|---|---|
| 1 KICK | 低音鼓 | 每小节第 1 拍，正拍骨架 | `#5B8CFF` |
| 2 SNARE | 军鼓 | 第 2、4 拍，回拍感 | `#FF7A59` |
| 3 CH | 闭镲 | 8 分填充，正反拍 | `#35D0BA` |
| 4 OH | 开镲 | 乐句末尾 / 段落切换 | `#C084FC` |

### 谱面密度

| 档位 | 每小节音符 | 内容 |
|---|---|---|
| 入门 | 4 | 全正拍，只练稳 |
| 熟练 | 8 | 加反拍 CH |
| 挑战 | 11–13 | 16 分加花 + 切分，每 2 小节一次 |

> 难度提升靠**密度与切分**，不靠加快 BPM。加快 BPM 会让"稳"的训练失效。

## 6. 模式 B：旋律家（练音感 + 双手）

**左侧 PAD 轨 + 右侧 MELODY 5 列，共一条判定线。**

```
┌────────┬────┬────┬────┬────┬────┐
│  PAD   │ C  │ D  │ E  │ G  │ A  │
│ 1.5 份 │ 1  │ 1  │ 1  │ 1  │ 1  │   ← 横向单位
│        │    │    │    │    │    │
│ 长按   │      点按，列 = 音高      │
│ 和声   │      五个音 = 当前调五声  │
├────────┴────┴────┴────┴────┴────┤   ← 判定线
│  按住  │        点击             │
└─────────────────────────────────┘
```

宽度分配：PAD 1.5 单位，5 个旋律列各 1 单位 → 375 屏下 PAD 88px、每列 58px。

### 6.1 PAD 轨（左）

- 长按（Hold），跨 1.75 小节，落在和弦根音。
- 按住渐入 120ms，松手渐出 200ms。
- 提前松手 → 按持续比例结算，**不判错、不断连击**（松手是"少弹"，不是"错"）。
- **默认开启**，设置里可关闭。关闭后 MELODY 占满全宽，变成纯旋律模式（新手友好）。
- 训练价值：和声感 + 持续稳定。

### 6.2 MELODY 区（右，5 列）

- 点按（Tap），列 = 音高，一个八度内的五声音阶。
- 各调音高表：

| 曲目调 | 五声音高（C 调记法） | MIDI |
|---|---|---|
| C | C D E G A | 72 74 76 79 81 |
| G | G A B D E | 67 69 71 74 76 |
| D | D E F# A B | 74 76 78 81 83 |
| F | F G A C D | 65 67 69 72 74 |
| Am | A C D E G | 69 72 74 76 79 |

- **音高判定可开关（默认开）**：
  - 开：必须点中正确的列。点错列 → 该音符最高只能判 GOOD，并播放你点到的那一列的音（**柔性失败**：听着跑调，但不刺耳，因为仍在五声内）。
  - 关：旋律区任意位置点击都算命中最近音符 → 退化为纯节奏模式。
- 这个开关同时是**难度阀**和**体验对照实验**，用于验证"音高是否太难"。

### 6.3 辅助渐隐（音感教学设计）

| 阶段 | 显示 | 依赖 |
|---|---|---|
| L1 入门 | 列头显示音名 + 音符带音名 | 眼睛 |
| L2 熟练 | 列头显示音名，音符不带 | 眼 + 记忆 |
| L3 挑战 | 列头仅在最后 0.5s 高亮 | 耳朵 |

## 7. 判定、计分与反馈

### 7.1 判定窗口（固定毫秒，不随 BPM 缩放）

| 档位 | PERFECT | GREAT | GOOD | 判定偏移默认 |
|---|---|---|---|---|
| 休闲 | ±55ms | ±100ms | ±150ms | 0 |
| 标准 | ±40ms | ±75ms | ±120ms | 0 |
| 严格 | ±25ms | ±50ms | ±90ms | 0 |

> 40ms ≈ 人类"同时"感知阈值的 2 倍，是商业节奏游戏通用基准。

### 7.2 计分

| 判定 | 基础分 | 连击 |
|---|---|---|
| PERFECT | 100 | +1 |
| GREAT | 70 | +1 |
| GOOD | 40 | +1 |
| MISS | 0 | 清零 |

- 连击加成：每 10 连击 +2%，上限 +20%。**只有加成，没有惩罚。**
- 空击（点到没有音符的位置）：播放音效，**不扣分不断连**。解压优先。
- Hold：按持续比例 × 头部判定的基础分。

### 7.3 三维结算（替代单一分数）

| 维度 | 算法 | 能力 |
|---|---|---|
| **准确率** | 加权得分 / 满分 | 打得准 |
| **稳定度** | `clamp(100 - σ(偏差ms) / 1.5, 0, 100)` | 打得稳 |
| **完整度** | `1 - miss / 总音符` | 有没有漏 |

单次 PERFECT 是运气，σ 小才是节奏感。结算页给一句话诊断：

| 偏差均值 | 文案 |
|---|---|
| < −40ms | 你整体偏早 40ms，可以再等一下 |
| −40 ~ +40ms | 节奏很稳 |
| > +40ms | 你整体偏慢 35ms，试着提前一点 |

等级：准确率 ≥95 S / ≥88 A / ≥78 B / ≥65 C / 其余 D。

### 7.4 失败反馈

| 事件 | 表现 |
|---|---|
| MISS | 判定线一次灰色涟漪，音符淡出，**backing 继续** |
| 断连击 | 数字缩小淡出，无红闪、无震屏 |
| 错轨 | 该轨轻微亮一下，不扣分 |

### 7.5 Zone

连续 50 连击进入 Zone：背景转暖、判定线加粗、分数 ×1.2、粒子增多。
**用奖励制造高潮，而不是用惩罚制造紧张。**

## 8. 单局结构

16 小节，四段（4/4 @75BPM ≈ 51 秒）：

| 段 | 小节 | 内容 | 感受 |
|---|---|---|---|
| A 起 | 0–3 | 稀疏，只鼓 + 贝斯 | 进入状态 |
| B 承 | 4–7 | 加 PAD，密度提升 | 跟上 |
| C 转 | 8–11 | 加花 / 切分，情绪最高 | Zone |
| D 合 | 12–15 | 回稀疏，长音收束 | 松下来 |

结尾必须"落"，不能戛然而止。

---

## 9. 音频架构

| 层 | 内容 | 控制方 |
|---|---|---|
| L0 backing | 鼓 + 贝斯 + PAD 伴奏 | 全自动，**永不停止** |
| L1 guide | 旋律参考音（新手可开） | 可关 |
| L2 player | 玩家击打音 | 玩家 |

**MISS 时只是不播放 L2，L0 继续 → 音乐不断。** 这是"解压"的技术前提。

- 原型阶段：WebAudio 实时合成（scheduler + lookahead 0.25s）。
- 小程序阶段：预渲染 backing（60s mp3 ≈ 950KB）+ 短采样池（鼓 4 + 音高 5，单文件 <20KB）。
- 曲目来源：**无版权 loop 素材改编**，替换掉原型里的合成音色。

## 12. 解压机制清单

1. 音乐永远不会被玩坏
2. 无血条、无 Game Over、无倒计时
3. BPM 65–75（接近静息心率上沿，生理上诱导放松）
4. 判定线随拍呼吸、背景色温随和弦缓慢漂移（周期 ≥ 8s）
5. 一局 55 秒，随时可退，退出保留成绩
6. 只有加分，没有扣分
7. 结尾必须"落"（长音收束）

## 13. 无尽练习模式（保留随机谱面）

固定谱面用于"打歌/比成绩"，随机谱面用于"练手感"。

| | 打歌模式 | 无尽练习 |
|---|---|---|
| 谱面 | 固定（seed 固定） | 每轮随机 |
| 时长 | 16 小节 | 无限 loop，可随时停 |
| 结构 | A/B/C/D | 每 8 小节循环，逐轮加花 |
| 结算 | 三维 + 等级 | 只显示稳定度与总时长 |

v1 原型先不做，接口预留（`chartSeed` 参数）。

## 14. 原型规格（真源声明）

> **`prototype/` 是交互与视觉的唯一真源。**
> 后续小程序实现必须对齐：布局常量、颜色、动效曲线、判定数值、文案。
> 若小程序需要偏离，先改原型，再抄。

| 文件 | 职责 |
|---|---|
| `prototype/index.html` | 结构：首页 / 演奏 / 结算 / 设置 |
| `prototype/style.css` | 视觉：色板、字号、圆角、过渡 |
| `prototype/app.js` | 逻辑：谱面生成、音频、判定、渲染 |

顶部 `CFG` 对象集中所有可调数值，改玩法不改逻辑。

## 15. 小程序实现要点

| 点 | 说明 |
|---|---|
| Canvas | `type="2d"`，按 `dpr` 缩放，`requestAnimationFrame` 驱动 |
| 触摸 | `bindtouchstart/move/end`（多点），不用 pointer 事件 |
| 音频 | `wx.createWebAudioContext`；backing 用 AudioBufferSourceNode，击打音用采样池 |
| 时钟 | **只用一个时钟**：audio context 的 `currentTime`。禁止混用 `Date.now()` |
| 延迟 | 首次进入做一次"听 click 敲屏"校准（8 次取均值），存本地 |
| 包体积 | 主包 1 首，其余分包下载 |
