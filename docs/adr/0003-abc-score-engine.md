# ADR 0003 · 谱用 ABC，风格用预设

- 状态：已采纳
- 日期：2026-10-24
- 相关：[`docs/abc.md`](../abc.md)、`docs/tech.md` §6.4 / §6.8、`docs/tech-lofi.md` §9、
  `apps/pwa/src/engine/abc/`

## 背景

到 v1.6，七首曲子的旋律是 `compose.ts` 里的手写字符串（一小节一行、16 个格子、`.` 是留白）。
它能写出动机，但有三个绕不过去的限制：

1. **加一首曲子要改 TypeScript。** 旋律、低音、鼓、混音全塞在 `Composition` 一个对象里，
   写谱的人得懂字段名与格子对齐。
2. **只有旋律和低音能写。** 铺底与和声是节奏型算出来的，想写一条具体的副旋律没有地方放。
3. **谱与风格粘在一起。** 同一段旋律想听摇滚版，得复制一份对象再改六七个字段 ——
   而这正是"不同风格一套乐器"要避免的事。

## 候选（2026-10-24 实测）

| 方案 | 体积 | 协议 | 它给什么 | 结论 |
|---|---|---|---|---|
| **abcjs 6.7.2** | `dist/abcjs-basic-min.js` **511,968 B**（整包解包 6.1 MB） | MIT | 排版 AST + SVG + MIDI | 不采用 |
| chamber-abc 0.2.1 | WASM | MIT | parser / analyzer / formatter | 不采用：2026-01 才发布，生态未验证 |
| musicxml-io 0.12.2 | 未知 | MIT | ABC ⇄ MusicXML 往返 | 不采用：比需要的多一层 |
| abcmidi（abc2midi） | C 命令行 | GPL | ABC → MIDI | 只能构建期用，运行时要解析 |
| **自写子集** | 源码 560 行（含注释），产物 +18 KiB | 本项目 | 音符 / 时值 / 小节 / 和弦 / 声部 | **采用** |

abcjs 的 AST 实测（`abcjs.parseOnly`，谱面 `"G" d4 g2 a2 g4 d4 | z8 ^C,4 D,,4`）：

```
note.pitches[0] = { pitch: 8,  verticalPos: 8 }     // d → 8（音级，不是 MIDI）
note.duration   = 0.25                              // 全音符的分数
C, → pitch -7    D,, → pitch -13
```

也就是说：**调号、八度、小节、十六分格、和弦对位，全都要在拿到 AST 之后再算一遍。**
我们需要的转换层一行都省不掉，反而多背 500 KiB。

## 决策

1. **谱用 ABC，一首一个文件**：`apps/pwa/src/songs/*.abc`。
2. **自写子集解析器**（`engine/abc/parse.ts`），只认演奏需要的东西：
   八度、调号、临时记号、时值、连音线、小节线、反复、和弦记号、多声部、`%%OB` 指令。
3. **风格用预设**（`engine/abc/style.ts`），`%%OB style lofi` 取整套编制与混音，
   其余 `%%OB` 逐字段覆盖。
4. **谱与风格在 `toScore.ts` 汇合**，产出引擎原有的 `Score`，排程器一行不用改。

## 为什么自写

| 理由 | 具体 |
|---|---|
| **体积** | 预缓存 630.61 KiB。引 abcjs 是 +512 KiB（+81%）；自写之后整包 +18 KiB（含两个谱与转换层） |
| **AST 不对路** | 上面实测：pitch 是音级。我们要的是 MIDI + 格号，转换层跑不掉 |
| **指令** | `%%OB`（风格、鼓、混音）abcjs 不认识，还得自己解析一次 |
| **错误定位** | 警告带"第 n 行"，写谱的人能直接改；abcjs 的警告是给排版用的 |
| **可控的边界** | 不支持的写法宁可明确警告，也不要"看起来支持、听着不对" |

代价是：**不支持完整的 ABC**。跳房子 `[1/[2`、不等分音符 `>`/`<`、装饰音的实际时值、
歌词都不做 —— 它们对一个循环播放的游戏 BGM 没有价值。

## 验证

| 手段 | 内容 | 结果 |
|---|---|---|
| 自检 | `pnpm --filter @o-beat/pwa abc:check`，25 项：八度 / 调号 / 本小节还原 / 时值取整 / 连音线 / 反复 / 和弦落格 / 和弦三音同格 / 两声部 + 两首谱逐格 + 换风格 | 全通过 |
| 逐格回归 | 两首谱解析出的 `lead` / `bass.line` / 每小节和弦根音，与搬走前的手写数据完全一致 | 一致 |
| 音频 | 与 v1.6 的录音比五段能量 | 四个音乐频段最大差 0.6 dB、RMS 差 0.4 dB（见 `docs/abc.md` §5.1） |

## 影响

- **加一首曲子** = 放一个 `.abc` + 在 `abc/songs.ts` 登记一行。不改引擎、不写 TS 数据。
- `Score` 多一个 `leadDur`（每个旋律音的时值）。手写编曲不填，沿用原来的 3.2 格。
- `compose.ts` 从七首降到五首；`chords.ts` 抽出和弦名解析，手写路径与 ABC 路径共用。
- `SongLike` 多一个可选的 `abc`：曲目可以自带一份谱（试听、外部谱、以后的自定义曲）。
- 曲目的 `bpm` / `chords` 与谱面不一致时，以谱面为准并在 DEV 控制台警告。
